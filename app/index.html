Import invoices from Zoho Books

In Zoho Books open Invoices, use the \u22ef menu, then Export Invoices as CSV and upload it here. You can also paste JSON from a Zoho Books custom function (an invoices list using Zoho field names such as invoice_number, customer_name, date, due_date, total, balance, status). Optional: billing_address (or billing_city, billing_country and similar) adds the billing location. Re-importing updates invoices that already exist.
